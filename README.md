# FORESIGHT

## Demand Forecasting and Inventory Intelligence

FORESIGHT is a Python-based dashboard designed to help users
explore sales trends, estimate future demand, and monitor inventory.

## Technologies

- Python
- Streamlit
- Pandas
- Plotly

## Features

- Sales overview
- Interactive sales charts
- Demand forecasting
- Inventory monitoring
- Estimated days of stock remaining

## How to run

1. Install Python 3.12.
2. Install the required libraries:

   pip install -r requirements.txt

3. Start the application:

   streamlit run app.py

## Forecasting method

The application uses the average of the latest seven sales
observations as a baseline forecast.
